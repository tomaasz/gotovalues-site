## 2025-04-05\n\nWhen lazy-loading context providers (like `posthog-js/react`) that wrap the entire application's `children`, do not conditionally render the provider or change the element wrapper during the loading phase (e.g., swapping `<Fragment>` to `<PHProvider>`). Doing so causes React to fully unmount and remount the application subtree. To defer heavy analytics scripts without losing initial tracking events or triggering React subtree remounts, render the Context Provider immediately with a `Proxy` object passed as the initial client. The proxy should trap method calls to queue them until the library asynchronously loads, and explicitly return `undefined` (not `Array.prototype.push`'s numeric return value) to prevent downstream bugs.
