## 2024-05-14 - Loading State Visibility & Textarea Layout
**Learning:** For forms that trigger asynchronous actions (like sending an email or saving data), standard text changes like "Wysyłanie..." are often insufficient or easily overlooked. Users benefit from explicit visual feedback, such as a spinning loader icon. Additionally, unbounded `<textarea>` resizing can easily break a carefully crafted grid layout.
**Action:** When creating or updating form components, always include a visual loading indicator (e.g., `<Loader2 className="animate-spin" />`) disabled on submission, and explicitly apply `resize: vertical;` to `textarea` elements in the global CSS to maintain layout integrity.## 2026-03-28 - Explicit Required & Optional Labeling in Forms\n**Learning:** While `required` HTML attributes are functional for modern browsers and basic validation, users benefit significantly from explicit visual indicators in forms. In a form where most fields are required, explicitly marking the rare optional field (e.g., `(opcjonalnie)`) while marking the rest with a colored `*` provides the clearest, fastest cognitive parsing of what information is actually needed.\n**Action:** When working on forms, ensure required fields have an `<span aria-hidden="true" className="required-indicator">*</span>` (to prevent redundant screen reader announcements) and optional fields explicitly state their status using `<span className="optional-indicator">(opcjonalnie)</span>`.
