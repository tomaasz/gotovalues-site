## 2024-05-14 - Loading State Visibility & Textarea Layout
**Learning:** For forms that trigger asynchronous actions (like sending an email or saving data), standard text changes like "Wysyłanie..." are often insufficient or easily overlooked. Users benefit from explicit visual feedback, such as a spinning loader icon. Additionally, unbounded `<textarea>` resizing can easily break a carefully crafted grid layout.

## 2024-05-15 - Skip to Content Links in Next.js
**Learning:** Adding a "skip to main content" link for keyboard accessibility requires two often-overlooked details when targeting a `<main>` container in Next.js: First, the targeted container needs `tabIndex={-1}` to receive programmatic focus from the browser when the anchor is activated. Second, because `tabIndex={-1}` makes the element focusable, the browser will wrap the entire `<main>` block in an ugly default focus ring unless explicitly removed using `outline: none` on `:focus`.
**Action:** When implementing skip links, ensure the target element (usually `<main id="main">`) has both `tabIndex={-1}` in the HTML/JSX and `:focus { outline: none; }` in the CSS.
