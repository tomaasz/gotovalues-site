# gotovalues Homepage Copy Design

## Approved Brief

- Page type: homepage
- Primary audience: local business client, not recruiter
- Best-fit segment for first campaign: small and mid-sized production or processing companies with operational complexity
- Core offer: custom web applications and practical AI tools for real processes
- Primary CTA: conversation about one concrete process problem
- Awareness level: problem-aware, not product-aware

## Copy Direction

The homepage should stop sounding like a broad digital services site. It should read like a focused offer for firms that already feel operational friction: too much Excel, too many documents, too much manual status chasing.

The message order should be:

1. Recognize the pain
2. Name the type of solution
3. Show a practical working style
4. Reinforce credibility with real products
5. Ask for a conversation about one process

## Tone

- direct
- practical
- anti-buzzword
- business-first

The page should avoid vague “innovation” language and avoid positioning AI as the main product. AI stays subordinate to the business problem.
